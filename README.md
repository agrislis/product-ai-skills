# Product AI Skills

> 🇷🇺 Описание на русском доступно ниже / Russian description is available below

Collection of AI skills for **Product Managers** and **Business Analysts**.

## Structure

### [`business-requirements-skills/`](business-requirements-skills/)
Skills related to business requirements.

- **[`elicitation/`](business-requirements-skills/elicitation/)** — Requirements collection and processing pipeline:
  - [`questions-for-client`](business-requirements-skills/elicitation/questions-for-client/) — Generate stakeholder interview questions
  - [`answer-analyzer`](business-requirements-skills/elicitation/answer-analyzer/) — Analyze stakeholder answers, gaps and readiness
  - [`task-formulator`](business-requirements-skills/elicitation/task-formulator/) — Formulate a concise prompt for business analysis
  - [`business-analyst`](business-requirements-skills/elicitation/business-analyst/) — Full business process analysis document
  - [`requirements-orchestrator`](business-requirements-skills/elicitation/requirements-orchestrator/) — Orchestrates the full pipeline

### [`product-skills/`](product-skills/)
Product-oriented utility skills:

- [`improvement-request-formatter`](product-skills/improvement-request-formatter/) — Format improvement / feature requests into a strict 7-point template
- [`north-star-metric`](product-skills/north-star-metric/) — Define or critique North Star Metric and input metrics

## How to use

Copy the desired skill folders into your Grok skills directory (`~/.grok/skills/` or equivalent).

Each skill is self-contained in its own folder with a `SKILL.md` file.

Коллекция ИИ-навыков для **продакт-менеджеров** и **бизнес-аналитиков**.

Навыки, связанные с бизнес-требованиями.

- **[`elicitation/`](business-requirements-skills/elicitation/)** — Конвейер сбора и обработки требований:
  - [`questions-for-client`](business-requirements-skills/elicitation/questions-for-client/) — Генерация структурированных вопросов для стейкхолдеров
  - [`answer-analyzer`](business-requirements-skills/elicitation/answer-analyzer/) — Анализ ответов стейкхолдеров, пробелов и готовности

  - [`business-analyst`](business-requirements-skills/elicitation/business-analyst/) — Полный документ бизнес-анализа процесса
  - [`requirements-orchestrator`](business-requirements-skills/elicitation/requirements-orchestrator/) — Оркестрация полного конвейера

### [`product-skills/`](product-skills/)
