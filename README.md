# Product AI Skills

Collection of AI skills for **Product Managers** and **Business Analysts**.

## Structure

### `business-requirements-skills/`
Skills related to business requirements.

- **`elicitation/`** — Requirements collection and processing pipeline:
  - `questions-for-client` — Generate stakeholder interview questions
  - `answer-analyzer` — Analyze stakeholder answers, gaps and readiness
  - `task-formulator` — Formulate a concise prompt for business analysis
  - `business-analyst` — Full business process analysis document
  - `requirements-orchestrator` — Orchestrates the full pipeline

### `product-skills/`
Product-oriented utility skills:

- `improvement-request-formatter` — Format improvement / feature requests into a strict 7-point template
- `north-star-metric` — Define or critique North Star Metric and input metrics

## How to use

Copy the desired skill folders into your Grok skills directory (`~/.grok/skills/` or equivalent).

Each skill is self-contained in its own folder with a `SKILL.md` file.
