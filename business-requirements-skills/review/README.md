# Requirements Review

> 🇷🇺 Описание на русском доступно ниже / Russian description is available below

Skills for reviewing and validating requirements artifacts (Business Requirements vs Technical Specifications).

## Skills

| Skill | Purpose |
|-------|---------|
| [`bt-tz-compliance-review`](bt-tz-compliance-review/) | Check Technical Specification (ТЗ / SRS / Design Spec) against Business Requirements (БТ / BRD), build traceability matrix, detect gaps, meaning distortions, excesses and conflicts |
