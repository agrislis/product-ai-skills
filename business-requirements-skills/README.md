# Business Requirements Skills

Skills related to **business requirements**.

## `elicitation/`

Pipeline for collecting and processing business requirements:

1. **questions-for-client** — Generate structured questions for stakeholders
2. **answer-analyzer** — Analyze answers, find gaps and contradictions
3. **task-formulator** — Create a concise prompt for business analysis
4. **business-analyst** — Produce a full business analysis document
5. **requirements-orchestrator** — Orchestrate the full end-to-end pipeline

Future skills (e.g. requirements review) will live in sibling folders inside `business-requirements-skills/`.
